# VANTA

Official app download and release announcement page.

## Downloads

A replacement release is being prepared and verified. APK downloads are temporarily unavailable on this page while release-signing security is updated.

When a verified release is ready, it will appear in [Releases](https://github.com/drewk312/VantaMusic/releases), with installation instructions and a SHA-256 checksum. Do not install APKs from unverified mirrors.

## About this repository

This public repository contains release information only. The application source code is maintained privately. Signing keys, passwords, server credentials, and development backups are not distributed here.

## Feedback

Report reproducible app problems in [Issues](https://github.com/drewk312/VantaMusic/issues). Include the app version and Android version, but never passwords, access tokens, account credentials, or other private information.
